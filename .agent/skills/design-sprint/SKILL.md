A five-day process for answering critical business questions through design, prototyping, and testing ideas with customers. Developed at Google Ventures.

## The 5-Day Sprint Process
```
Monday → Tuesday → Wednesday → Thursday → Friday
  Map      Sketch     Decide      Prototype    Test
```

## Monday: Map
- Write long-term goal: "What do we want to be true in 2 years?"
- List sprint questions (obstacles and unknowns)
- Map customer journey (5-15 steps)
- Expert interviews → How Might We (HMW) notes
- Pick target: which part of the journey to focus on

## Tuesday: Sketch (Individual, NOT group)
- Lightning demos: 3-minute inspiration from competitors/analogues
- Notes (20 min) → Ideas (20 min) → Crazy 8s (8 min) → Solution Sketch (30-90 min)
- Solution sketch = 3-panel storyboard, anonymous, self-explanatory

## Wednesday: Decide
- Art museum: silently review sketches, add dot stickers
- Heat map review: 3 min per sketch
- Straw poll (non-binding) then **Decider supervote** (wins)
- Build 10-15 panel storyboard for prototype

## Thursday: Prototype
- Build realistic facade (not working code)
- Goldilocks quality: looks real, doesn't work real
- Tools: Figma, Keynote, linked slides
- Roles: Makers, Stitcher, Writer, Collector, Interviewer

## Friday: Test (5 customers)
- 5-Act interview: Welcome → Context → Introduce prototype → Tasks → Debrief
- Observation room: team watches, takes notes (✓ ✗ ~)
- After all 5: look for patterns
- Decision: validated → build it | major issues → next sprint | failed → back to drawing board

## When to Sprint
✅ Run when: High-stakes decision, team stuck in debate, multiple solutions possible, new product/redesign
❌ Don't run when: Problem is clear, solution is obvious, can't get Decision Maker for full week

## Common Mistakes
| Mistake | Fix |
|---------|-----|
| Skip prototyping | Always prototype, even simple |
| Over-engineer prototype | Facade only, not working code |
| Test with wrong users | Screen for target customers |
| Explain prototype to users | Let them struggle, observe |
| No decision maker | Get Decider for full week |
