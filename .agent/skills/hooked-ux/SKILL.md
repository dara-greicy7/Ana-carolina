Framework for building habit-forming products. Based on a fundamental truth: habits are not created—they are built through successive cycles through the Hook.

## Core Principle
**The Hook Model** = a four-phase process that connects the user's problem to your solution frequently enough to form a habit.

```
Trigger → Action → Variable Reward → Investment
    ↑                                      │
    └──────────────────────────────────────┘
```

## Phase 1: Trigger
What prompts the user to take action? External (environment-driven) or internal (emotion-driven).
- External triggers: push notifications, emails, buttons, ads
- Internal triggers: emotions, routines, situations (boredom, FOMO, loneliness)
- Goal: move users from external to internal triggers over time

## Phase 2: Action
The simplest behavior done in anticipation of a reward. B = Motivation × Ability × Trigger.
- Six elements of simplicity: time, money, physical effort, brain cycles, social deviance, non-routine
- Reducing friction > increasing motivation
- Hick's Law: more choices = slower decisions

## Phase 3: Variable Reward
Anticipation of reward (not reward itself) creates dopamine.
- **Tribe**: social validation (likes, comments)
- **Hunt**: resources/information (feeds, search)
- **Self**: personal mastery (streaks, achievements)
- Predictable rewards lose power; variability sustains engagement

## Phase 4: Investment
Users invest (time, data, effort) that improves the product for next use.
- IKEA effect: users value what they invest effort into
- Investment loads the next trigger
- Types: data, content, reputation, skill, social connections

## The Habit Zone
| | Low Frequency | High Frequency |
|--|---------------|----------------|
| **High Perceived Value** | Viable product | **HABIT ZONE** |
| **Low Perceived Value** | Failure | Failure |

## Onboarding Checklist
- [ ] Is the first action obvious and easy?
- [ ] Can the user complete the core action in under 60 seconds?
- [ ] Does the user get immediate feedback?
- [ ] Is there a variable element (surprise, delight)?
- [ ] Do we ask for investment AFTER reward (not before)?
- [ ] Does the investment load the next trigger?

## The Manipulation Matrix
| | Maker Uses Product | Maker Doesn't Use |
|--|--------------------|--------------------|
| **Improves User's Life** | **Facilitator** ✅ | Peddler |
| **Doesn't Improve Life** | Entertainer | **Dealer** ❌ |

Aim to be a Facilitator. Never exploit vulnerable emotional states.
